Returns JSON with data of multiple rows.

§Example

let users = db.select(
    "SELECT id, name FROM users WHERE name LIKE %?%"
)?;

Returns:

[
  { "id": 2, "name": "Mark" },
  { "id": 5, "name": "Denmark" }
]
