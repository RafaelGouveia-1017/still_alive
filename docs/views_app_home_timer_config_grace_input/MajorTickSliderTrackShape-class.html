MajorTickSliderTrackShape

MajorTickSliderTrackShape class

A custom slider track that displays major duration markers.

The track renders the active and inactive portions of the slider and places visual markers at the durations defined by majorPoints.

This track shape is intended to be used with SliderThemeData.trackShape on a Slider.
