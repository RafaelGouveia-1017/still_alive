IntegrationService

IntegrationService class

Provides utility methods for managing external integrations.

IntegrationService centralizes integration-related operations such as displaying account summaries, discovering available destinations, testing accounts and destinations, connecting and removing accounts, managing destinations, and presenting provider-specific setup flows.

The service delegates persistence and provider-specific operations to the underlying generic integration API while keeping the local IntegrationInfo state synchronized with successful changes.
