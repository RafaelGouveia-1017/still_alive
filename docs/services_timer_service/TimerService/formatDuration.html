Formats a Duration into a compact human-readable string.

Zero-valued time units are omitted. For example, a duration of 1 hour, 5 minutes, and 30 seconds is formatted as 01h 05m 30s, while a duration of 30 seconds is formatted as 30s.

Returns 0s when the duration is zero.

Implementation

static String formatDuration(Duration duration) {
  final parts = <String>[];

  final hours = duration.inHours;
  final minutes = duration.inMinutes % 60;
  final seconds = duration.inSeconds % 60;

  if (hours > 0) {
    parts.add('${hours.toString().padLeft(2, '0')}h');
  }

  if (minutes > 0) {
    parts.add('${minutes.toString().padLeft(2, '0')}m');
  }

  if (seconds > 0) {
    parts.add('${seconds.toString().padLeft(2, '0')}s');
  }

  if (parts.isEmpty) {
    return '0s';
  }

  return parts.join(' ');
}
