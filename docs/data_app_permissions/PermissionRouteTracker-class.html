PermissionRouteTracker

PermissionRouteTracker class

Tracks navigation state related to permission-related routes.

This class uses RouteAware to monitor when permission or onboarding screens become active or inactive. It helps prevent redundant navigation to permission flows when the user is already interacting with them.
