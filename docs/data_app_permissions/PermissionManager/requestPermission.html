Future<PermissionStatus> requestPermission(
  1. Permission permission
)

Requests a specific permission from the user.

  • If the permission is permanently denied, the system settings page is opened and the current status is returned.
  • Otherwise, a standard permission request dialog is shown.

Returns the updated PermissionStatus after the operation.

Implementation

Future<PermissionStatus> requestPermission(Permission permission) async {
  var status = await permission.status;

  switch (status) {
    case PermissionStatus.permanentlyDenied:
      openAppSettings();
      return await permission.status;
    default:
      if (permission == Permission.locationAlways) {
        PermissionStatus status = await permission.request();
        if (status == PermissionStatus.denied) {
          openAppSettings();
          return await permission.status;
        } else {
          return status;
        }
      } else {
        return await permission.request();
      }
  }
}
